## Project Description

This project implements a calculator using
Python and Lark.

The calculator supports arithmetic expressions,
exponentiation, unary negation, parentheses,
and logarithms.

## Requirements:

- Python 3
- Lark

## Installation:

'pip install lark'

## Running the Calculator

Navigate to the Assignment1 directory.

Run:
python calculator_cfg.py "EQUATION"

Example:
python calculator_cfg.py "log 8 base 2^2"

Expected output:
1.5
